Investigation Timeline

Following the PICERL framework step by step

Identification
Discovered CPU outlier consuming 44,392 seconds 10% of total uptime CPU. Used PowerShell-based process enumeration.
PHASE 2
Investigation
Mapped 8-service ReasonLabs suite. Identified DNS interception, EDR module, and Windows Security Center manipulation.
PHASE 3
Eradication
Executed official uninstaller, verified registry cleanup, reset DNS configuration, re-enabled Windows Defender.

MITRE Mapping

Detection Engineering
Developed Sigma rules for SIEM deployment. Created PowerShell hunt scripts and KQL queries for blue teams.
